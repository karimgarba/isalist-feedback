# isalist — Feedback & Issues

Bug reports and feature requests for **[isalist](https://myisalist.com)**.

This repo has **no code** — it's just where the community reports problems and suggests ideas.

- 🐛 **Found a bug?** [Open a bug report](https://github.com/karimgarba/isalist-feedback/issues/new?template=bug_report.yml)
- 💡 **Have an idea?** [Request a feature](https://github.com/karimgarba/isalist-feedback/issues/new?template=feature_request.yml)
- 📋 Browse [existing issues](https://github.com/karimgarba/isalist-feedback/issues) first — a 👍 on an existing one helps us prioritise.

Please don't include passwords or private info. Thanks for helping make isalist better!
